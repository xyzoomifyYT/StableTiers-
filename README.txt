MCTIERS Website V2

Enthalten:
- MCTiers-inspiriertes Frontend
- HT1-LT5 Tier-System
- 11 PvP-Modi
- Spielerprofile
- öffentliche Rangliste mit Suche/Filtern
- Test-Anfragen
- Tester/Admin-Dashboard
- Tier-Vergabe nach Test
- ELO-System
- Test-Historie
- Re-Test-/Anfrage-Grundlage
- lokale Datenspeicherung via localStorage
- Datenexport als JSON
- responsive Handy/PC-Ansicht

WICHTIG:
Diese Version ist eine funktionierende Frontend-Demo. Die Daten werden lokal im Browser gespeichert.
Für eine echte öffentliche Website mit Accounts, Discord-Login, echter Datenbank, sicheren Tester-Rechten und serverweiter Synchronisierung braucht es ein Backend (z.B. Node.js + PostgreSQL/Supabase).
