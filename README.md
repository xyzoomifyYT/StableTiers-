# STABLETIERS – vollständige Tierlist

## Start
```bash
node server.js
```
Danach `http://localhost:3000` öffnen.

## Enthalten
- MCTiers-inspirierte Mobile/Desktop-Oberfläche
- Rankings und echte Tierlist-Ansicht (HT1–HT5 / LT1–LT5)
- UHC, Pot, NethOP, SMP, Sword, Axe, Mace, Crystal
- Suche, Profile, Regionen, Server-IP und Discord
- Admin-Panel für Spieler, Website-Ränge und Tier-Zuordnung
- API: `/api/data`, `/api/players`, `/api/players/:name`

## Admin
Das Passwort ist in `server.js` konfiguriert. Vor dem öffentlichen Hosten ändern.
