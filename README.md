# StableTiers

Minecraft PvP Tierlist website inspired by the general tierlist workflow.

## Login
The website asks for the player's Minecraft in-game name before showing the site. The current profile is tied to that name in the browser's localStorage.

## Important
This is a frontend/local demo. The username is NOT securely verified against Mojang/Microsoft. For a real public StableTiers platform, use a backend/database and proper authentication (ideally Microsoft/Minecraft account verification).

## Files
- index.html – profile + tierlist
- rankings.html – rankings
- tests.html – test requests
- rules.html – rules
- admin.html – tester/admin demo
- css/style.css – shared design
- js/app.js – shared state/login
- assets/background.png – background
- assets/logo.svg – StableTiers logo
