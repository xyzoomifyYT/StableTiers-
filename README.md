# StableTier

Eigenständige Minecraft-Tierlisten-/Testplattform als statische Demo.

Enthält Spielmodi wie Sword, Spear, Mace, Axe, Crystal, NethSMP, Pot, UHC, Boxing, BedWars, SkyWars, The Bridge, Parkour, Survival, Creative, SMP, Manhunt, TNT Run, Spleef, FFA, BuildUHC, Combo, Debuff, Speed und Bow.

Funktionen: Modus-Seiten, Testanfragen, Meine Tests, Testerbereich, Tier-Vergabe, Spielerprofile und Ranglisten pro Modus.

Für ein echtes öffentliches Mehrspieler-System braucht es zusätzlich Backend, Datenbank, Login und echte Match-/Tester-Logik. Diese Version speichert die Demo-Daten lokal im Browser.
